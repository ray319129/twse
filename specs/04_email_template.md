## 設計重點

1. **重要的放最上面**:自選池 + 訊號原因 + 公司資訊一起呈現,你不用點進去就知道為什麼觸發
2. **絕不寫「建議買進」**:只寫「觸發 X 條件」
3. **多訊號交集才上榜**:單一訊號不寄(會太吵)
4. **負面訊號也寄**:自選池中跌破均線、放量殺出 → 用 ⚠️ 標,免得你錯過警訊
5. **附產業 + 月營收 + 近期新聞**:降低你只看技術面下決策的機率
6. **每筆都有網頁連結**:點過去看 K 線 + 完整資訊 + 全部新聞
7. **大盤 + 明日重點**:免得你看完選股還要去別的網站查

## 觸發 Email 的條件

| 場景 | 寄不寄? |
|---|---|
| 自選池中有股票觸發**任何**多訊號交集 | ✅ 寄 |
| 自選池中有股票觸發**負面警告**(跌破均線、放量殺出) | ✅ 寄 |
| 自選池中沒任何觸發,但全市場有符合條件的 | ✅ 寄(但主旨改) |
| 完全沒符合條件的(罕見) | ❌ 不寄,免得你習慣性忽略 |
| 資料抓取失敗 | ✅ 寄 `[警告]` 信 |
| 假日 | ❌ 不跑 |
