# 短線信心排序 v1(取代「符合條件就全列出」)

## 為什麼改

舊版是「**過濾器**」:任何符合某條件的股票全部列出。在 2128 檔的市場裡,稍微鬆一點的條件就命中數百檔
(實測某日「醞釀區」高達 **731 檔**),等於沒篩 —— 而且領先訊號還會抓到「今天已經漲停」的股票,
變成追高,跟使用者最初抱怨的「延遲、追高」一模一樣。

新版是「**排序器**」:用一個 0~100 的信心分把全市場排序,**只取最高分的少數**(核心 10 + 觀察 20)。
程式見 [`scripts/scoring.py`](../scripts/scoring.py),參數在 `config/screeners.yaml` 的 `ranking:` 區塊。

## 設計給誰

短線交易者(隔日沖 / 隔週 / 月內)。所以評分偏重「**短線可執行性**」:量能、相對強度、新鮮觸發,
並排除已噴出的股票。

## 信心分組成(0~100)

| 構面 | 權重 | 內容 |
|---|---|---|
| 趨勢健康 | 25 | 收盤 vs 5/20/60/120MA 的排列、季線是否上揚 |
| 相對強度 | 25 | 近 60 日報酬 vs 大盤(`rs_ratio`),相對強弱線是否走揚 |
| 短線時機/量能 | 25 | 量能擴張(`vol_ratio`、`vol_ma5/vol_ma20`)+ 近 10 日動能 |
| 品質估值 | 15 | TWSE 估值快照:本益比合理、殖利率、股價淨值比(濾掉 PE 80 倍的投機股) |
| 流動性 | 10 | 日均成交金額(收盤×20日均量),低於門檻直接淘汰 |

**過熱重罰(× 0.55):** 5 日漲 > 22% 、乖離 20MA > 18% 、RSI > 88 、或今日漲停。
→ 解決「追到已經噴掉的股票」。

## 兩層輸出

- **核心(core,≤10):** 今天出現**新鮮觸發** + 未過熱 + 高分。
  - 觸發 = 帶量突破 20 日高(量 ≥ 1.5 倍且收紅) **或** 多頭回測支撐轉強(站季線、貼近 20MA、今日轉強)。
  - 這層是「**隔日沖 / 隔週可考慮進場**」的標的。
- **觀察(watch,≤20):** 高分但**還沒觸發**,在蓄勢(布林收斂 或 相對強度剛轉強)。放口袋盯,等發動。

每檔標 **動能 / 品質 / 均衡** 型。

## API 額度設計(重要)

FinMind 免費版額度有限。舊版對上百檔抓籌碼直接打爆(402,之後整個 run 資料全空)。

新版流程:
1. **全市場排序只用免費資料**(yfinance 價格 + TWSE 估值快照,各一次)。
2. **只對入榜的核心 + 自選池**(約 15 檔)才花 FinMind 抓籌碼/財報。
3. 觀察層的表格只用評分階段已有的欄位,完全不補抓。

→ FinMind 呼叫從數百次降到約 75 次,遠離 402。

## 可調參數(`config/screeners.yaml` → `ranking:`)

```yaml
ranking:
  core_count: 10
  watch_count: 20
  min_score: 45               # 低於此分不入榜(寧缺勿濫)
  min_dollar_volume: 30000000 # 流動性門檻(日均成交金額)
  enrich_top_n: 30            # 最多補抓 FinMind 的檔數
```

嫌名單太少就降 `min_score`;嫌雜就升 `min_score` 或 `min_dollar_volume`。

## 老實話

短線交易要扣掉手續費 + 0.15% 證交稅後**穩定贏 ETF 非常難**,本系統只是把「該盯哪些」縮到可執行範圍,
不是印鈔機。核心層也只是「值得研究的進場候選」,進場前仍須看量能續強、大盤位階、停損紀律。
